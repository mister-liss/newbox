newbox

Editor setup for a machine you just sat down at: gvim, Intel One Mono, the vimrc, and a window sized to fit comfortably.

Windows

curl.exe -fsSL https://newbox.stevenmliss.com/newbox.ps1 | iex

Run it from an administrator PowerShell — it registers a scheduled task at highest privileges. curl.exe spelled out, because bare curl is an alias for Invoke-WebRequest in Windows PowerShell 5.1.

Linux

curl -fsSL https://newbox.stevenmliss.com/newbox.sh | sh

Editor only. The AutoHotkey layer is Windows-only; on Linux that job belongs to the window manager.
